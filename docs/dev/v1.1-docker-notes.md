## 1. 核心决定（定稿）

1. **去掉 auto。** `deployMode ∈ {local, docker}`，`""` = 用户尚未选择。
   `"source"` 改名为 `"local"`。没有任何自动切换。
2. **首次只看镜像给默认。** 第一次遇到未选择状态时，只检查 `imageNames`
   （默认 `["strata"]`）里是否有镜像存在：有 → 默认 `docker`，否则 `local`；
   结果写入 `deployMode`，此后只听显式选择。
3. **两模式互斥，切换先停旧。** `switchDeployMode()` 先解析当前模式，若它在
   running/starting 就先 `stop()`，再保存新模式与字段。UI 在切换前弹确认。
4. **配置页入口分流。** 面板配置表单顶部两个互斥选项；选中哪个就只渲染哪套
   字段（本机：目录 / Python / 配置文件；Docker：镜像 / 容器 / 卷），另一套
   完全隐藏。
5. **Docker 以镜像为锚，App 负责创建。** 原「App 不创建容器」作废。App 用
   首次接入时采样并持久化的 `dockerRunConfig`（`docker inspect` 得到）创建/
   重建容器；没有容器可采样时退化为官方 `docker run` 配方（`--gpus all`、
   `--ulimit memlock`、`/data` 卷、发布端口）。
6. **更新转发。** `routes/update.js` 里本机继续走原源码管线；docker 模式转
   `DockerDeployer.update()`（有 `Dockerfile` 就 `docker build` 换镜像，再用
   采样参数重建容器，失败回滚旧容器名）。
7. **仅 Linux。** `deployMode === "docker"` 在非 Linux 上被强制回 `local`；
   manifest / UI 也只在 Linux 提供 Docker 选项。

## 3. 关键实现点

- **端口/Key 缓存**：`routes/requests.js` 用 `resolvePort(cfg)` /
  `resolveApiKey(cfg)` 只拿得到插件配置。docker deployer 在 status/检测时把
  实际宿主端口与 Key 记进 `common.js` 的进程内 `dockerRuntime` 缓存；
  `resolvePort/resolveApiKey` 在 `deployMode === "docker"` 时读缓存。路由零改动。
- **镜像默认检测不创建容器**：`resolveDeployMode` 只调用 `imageExists`，不看
  `docker ps`。
- **停止 grace**：`docker stop -t <dockerStopTimeoutSec>`（默认 60s，官方要求）。
- **停着的容器读配置**：`docker exec cat` 失败时回退 `docker cp <name>:<path> -`。
- **`docker inspect --type container`**：避免同名镜像被当成容器。
- **旧容器回滚**：重建前 `rename` 成 `<name>.prev-<ts>`，失败时 `rm -f` 新容器
  再 rename 回来并启动。

## 4. 实机验证（本机 Linux，docker 29.9.0）

已起的 `strata` 容器（`strata:latest`，`/data` 卷）：

- **状态**：`state=running`、`deployMode=docker`、`port=8080`、
  `imageVersion={tag:"strata:latest",created:...}`、`configSummary`/`metrics`/
  日志行正确，`version.local=0.1.41`。
- **配置读取**：`getConfigView` → `hasConfig=true`，context/kv/mtp/port 正确。
- **日志**：`readLogs` 从容器内 `strata-iq3_s.log` 取到尾行并解析出 pp/tg/
  专家缓存/KV 命中。
- **启停**：`stopService` → 容器 `exited`；`startService` → `created=false`、
  `state=starting`，随后 `docker` 状态回到 `running`。停止用了配置的 grace。
- **本机模式**：用真实 `<strata-dir>/strata-iq3_s.json` 跑
  `deployMode=local`，配置/状态形状无回归。
