## 任务 1：UI 多语言（核心）

支持 **6 种语言**：`zh`（中文）、`en`（英文）、`fr`（法语）、`ru`（俄语）、`ja`（日语）、`ko`（韩语）

### 实现方式

**新建 `ui/assets/i18n.js`**：
```js
export const STRINGS = {
  zh: { appName: "Strata 控制台", running: "运行中", ... },
  en: { appName: "Strata Console", running: "Running", ... },
  fr: { appName: "Strata Console", running: "En cours", ... },
  ru: { appName: "Strata Console", running: "Работает", ... },
  ja: { appName: "Strata コンソール", running: "実行中", ... },
  ko: { appName: "Strata 콘솔", running: "실행 중", ... },
};

export function detectLang() {
  // 按 navigator.language 匹配，找不到回退 en
}

export function t(key, lang) { ... }
```

**在 `panel.js` / `panel.html` 里**：
- 把所有硬编码文案改成 `t('key')`
- 启动时检测语言并渲染
- **可选**：加一个语言切换下拉（如果自动检测不准，用户能手动切）

### 需要翻译的文案（大约 35+ 条）

**从 `ui/panel.js` 和 `ui/panel.html` 里提取全部文案**，包括：
- 状态词：运行中 / 已停止 / 启动中 / 未配置 / 未安装 / 无配置
- 标签：模型 / 运行时长 / 端口 / 地址 / API Key / 版本 / 最新版本 / 上下文 / KV 量化 / 会话缓存 / 思考档位 / 生成 tg / 预填 pp / 专家缓存 / KV 命中 / 显存 / 内存 / 网络 / 本地 / 局域网
- 按钮：启动 / 停止 / 复制 / 保存 / 保存并重启 / 更新 / 确认 / 取消
- 提示：二次确认文案 / 遮罩文案 / 错误提示 / 配置引导
- 分组标题：版本 / 服务配置 / 性能 / 资源占用 / 日志 / 参数编辑

**翻译质量要求**：
- 技术术语要准确（如 "KV cache"、"prefill"、"MTP" 这类**保留英文原文**，不要硬翻）
- 界面文案地道、简洁（不是机翻腔）
